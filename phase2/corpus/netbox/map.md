# netbox (core package) — map

## What it is

`netbox/netbox/` is the Django project package: 116 modules, 14,106 lines of code, 33 of them test modules, and no data files. It owns no concrete database models and ships no migrations of its own; the only migrations in the subsystem belong to the `dummy_plugin` test fixture. [fg:subsystems:netbox] [fg:modules:netbox.tests.dummy_plugin.migrations.0001_initial]

Everything here is either project wiring (settings, URLs, middleware, WSGI) or an abstract base layer that the ten feature apps subclass: base models, generic views, base forms, base tables, base filtersets, REST viewsets/serializers, GraphQL types, and the plugin framework. Nothing outside the package references it by model-label string; the string-reference inbound list is empty, while the package's own eight string references all point outward to `extras`, `tenancy` and `core` models. [fg:model_refs:netbox.models.features:352] [fg:model_refs:netbox.models.features:487]

## Entry points

- `netbox.urls` is `ROOT_URLCONF`; it mounts home/search/login, each app under its own prefix, `/api/` (root, status, schema, swagger, redoc), `/graphql/`, `/media/`, and plugin UI/API patterns collected by `netbox.plugins.urls` from the registry. [fg:entrypoints:netbox.urls] [code:netbox/netbox/settings.py:480] [code:netbox/netbox/plugins/urls.py:11-36]
- `netbox.api.views` and `netbox.api.viewsets` are flagged as API entry points: the root and status views are routed directly, while every app viewset inherits from the viewset base. [fg:entrypoints:netbox.api.views] [fg:entrypoints:netbox.api.viewsets] [code:netbox/netbox/urls.py:44-55]
- Middleware order is `RemoteUserMiddleware` → `CoreMiddleware` → `MaintenanceModeMiddleware`, after Django's stock stack and `HtmxMiddleware`. [code:netbox/netbox/settings.py:449-463]
- Authentication backends are the configured `REMOTE_AUTH_BACKEND` list followed by `ObjectPermissionBackend`; the REST layer uses `TokenAuthentication` and `TokenPermissions`. [code:netbox/netbox/settings.py:512-518] [code:netbox/netbox/settings.py:673-695]

## Where change concentrates

- `settings.py` dominates: 960 commits by 52 authors from March 2016 to May 2025, roughly nine times the next module. [fg:churn:netbox.settings]
- The generic view layer is the second hotspot: `bulk_views` (103 commits, 14 authors) and `object_views` (81 commits) both touched as recently as June 2025, with `feature_views` at 20.
