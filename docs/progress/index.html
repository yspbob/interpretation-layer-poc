THE NEXT PIECE OF WORK

Use the first case to prepare the guidance test.

The H06 case explains what authentication logic can be shared and when a custom implementation takes responsibility. Next, use it to specify the agent inputs and assessment records, while checking which other cases belong in the trial. Keep separate examples for testing the assessor.

What needs to be built?

A way for separate agents to draft guidance, verify it and assess the result. Each must receive only its assigned files. Review existing tools before building this ourselves.

Coding comparisons and the interactive checker belong to the next two phases.
